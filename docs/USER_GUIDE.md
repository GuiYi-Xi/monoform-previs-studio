# MONOFORM 使用说明

MONOFORM 是一个面向分镜、构图和镜头预演的三维白模工作台。它适合先用低成本的白模人物、粗模场景和摄像机，把镜头关系、走位和动作节奏确定下来，再进入正式制作。

## 1. 界面总览

![MONOFORM 工作台总览](screenshots/monoform-overview.png)

| 区域 | 用途 |
| --- | --- |
| 顶部栏 | 新建、打开、保存、撤销/重做、工程设置，以及工程/PNG/MP4 导出 |
| 左侧「资源库」 | 添加人物、基础几何体、场景粗模和本地 GLB/GLTF |
| 左侧「场景层级」 | 按列表选择、隐藏或锁定对象 |
| 左侧「镜头」 | 管理多台摄像机、切换活动镜头和复制镜头 |
| 中央视口 | 编辑视角或当前摄像机视角；可旋转、平移、缩放和拖拽对象 |
| 右侧属性面板 | 编辑选中对象的位置、旋转、缩放、动作、骨骼、颜色或摄像机参数 |
| 右下监看器 | 始终预览主摄像机画面，可最小化、恢复或放大 |
| 底部时间轴 | 设置时间、播放动画和管理摄像机/角色/物体关键帧 |

## 2. 第一次使用：从空场景到一个镜头

1. 点击左侧人物卡片添加白模人物，再点击「方块」「圆柱」或场景粗模卡片搭建环境。
2. 在中央空白处拖动来观察场景：左键旋转、右键平移、滚轮缩放。
3. 选中对象后，用顶部「移动 / 旋转 / 缩放」切换操作，或直接在右侧滑块中输入精确值。
4. 点击右下「主摄像机 01」监看器中的摄像机按钮，选中场景里的主摄像机。
5. 进入右上「摄像机视角」，此时中央画面就是导出 PNG/MP4 使用的画面。

## 3. 场景与对象

### 添加资源

- **人物体型**：标准人物、女性人体、男性人体、修长人物、宽体人物。
- **基础物体**：方块、球体、圆柱、平面。
- **场景粗模**：拱门、楼梯、门、窗、桌子、椅子、沙发、屋顶、树木、车辆。
- **外部模型**：点击「导入 GLB / GLTF」选择本地模型；优先使用自包含贴图的 `.glb` 文件。

### 选择、隐藏和锁定

「场景层级」会列出摄像机和全部对象。点击名称选择对象；右侧圆点切换显示/隐藏；锁形按钮锁定对象。锁定后仍可查看属性，但不会被拖拽或变换误改。

对象重叠时，优先使用场景层级选择；在视口中按住 `Alt` 点击可选择被遮挡的底层模型。选中后再拖动，避免大体积模型抢选。

### 变换

- `W`：移动，拖红/绿/蓝轴分别沿 X/Y/Z 移动。
- `E`：旋转，支持水平、纵向和翻滚旋转；角色也会显示旋转圆环。
- `R`：缩放。点击「等比」锁定比例；也可分别锁定 X/Y/Z 轴。
- 顶部「世界坐标 / 局部坐标」可切换变换轴方向：搭场景通常使用世界坐标，沿物体自身朝向移动或旋转时使用局部坐标。
- 顶部磁吸按钮可开关吸附。开启后移动按 0.1 格、旋转按 5°、缩放按 0.1 对齐；关闭后可自由微调。
- 右侧「位置」「旋转」「缩放」滑块可进行精调。
- 「落到地面」会根据对象当前姿势、旋转和缩放后的实际最低点自动贴地，适合人物、外部模型和粗模物体。
- 「旋转归零」恢复三个旋转轴为 0°；「缩放归一」恢复三个缩放轴为 1。
- 点击「视图聚焦」可把编辑视角聚焦到当前对象。

## 4. 人物、动作和骨骼

### 动作预设

选中人物后，在右侧「人物」区域选择体型和「动作预设」。内置动作包括：自然站立、重心变化、行走/奔跑循环、接触步和跨步、点头、摇头、低头含胸、坐姿、招手、T 型绑定姿态等，共 23 个预设。

「动作相位」用于选择动作中的具体时刻。行走、奔跑、点头、摇头和招手等可循环动作可以打开「随时间轴循环动作」；关闭后只保留当前姿态，不会在播放或导出时持续变化。

### 手动调整骨骼

![人物骨骼编辑](screenshots/monoform-rig-editing.png)

1. 选中人物，按 `Q` 进入骨骼编辑。
2. 拖动青绿色手脚控制点，用 IK 调整四肢末端。
3. 拖动人物其他部位或金色骨骼点，旋转对应单根骨骼。
4. 也可以在右侧「完整骨骼」中选择骨骼，再用 X/Y/Z 滑块旋转。
5. 「脚底锁定」会让脚部 IK 保持当前脚底高度，只沿地面移动。
6. 「重置当前关节」只恢复当前骨骼；「重置全部骨骼」恢复整套绑定姿态。
7. 「保存当前姿势」会把姿势保存到本机浏览器，可随时再次应用或删除。
8. 「人物颜色」可为每个角色设置独立白膜颜色。

当前白模没有面部表情系统，悲伤、愤怒等情绪需要用低头、含胸、肩部和手臂姿态来表达。

## 5. 参考图

点击中央左上「上传参考图」，支持 PNG、JPEG 和 WebP。

- 「隐藏 / 显示」：临时关闭参考图，不删除文件。
- 「移动图片」：开启后直接拖拽图片位置；再次点击「锁定」结束拖拽。
- 「透明」：调整参考图不透明度。
- 「大小」：调整参考图缩放比例。
- 「居中」：恢复图片中心和默认大小。
- 「进入导出」：勾选后参考图会作为底层一起进入 PNG/MP4；不勾选则只作编辑辅助。
- 摄像机视角下，参考图会置于白模和场景底部，用于匹配构图，不会挡住模型。

导出前请先进入「摄像机视角」并确认参考图的大小、位置和「进入导出」状态；导出会使用当前摄像机画面和参考图参数。

## 6. 摄像机与镜头

### 摄像机列表

左侧「镜头」可以新建、复制、重命名、删除和切换镜头。每台镜头拥有独立的摄像机位置、方向、焦距、画面比例和关键帧。

![多镜头管理](screenshots/monoform-multi-shot.png)

### 摄像机参数

选中摄像机后可以调整：

- 位置：摄像机在三维空间中的 X/Y/Z 坐标。
- 摄像机旋转：X 俯仰、Y 水平、Z 翻滚。
- 焦距：18–120 mm，也可点击常用焦距预设。
- 画面比例：选择 16:9 等输出比例。

焦距改变的是视野范围，不是摄像机位置；广角会看到更多画面，长焦会压缩空间并放大主体。

### 摄像机视角与水平校正

- 「编辑视角」是布置场景用的固定观察相机，可以自由旋转、平移和缩放。
- 「摄像机视角」显示场景中主摄像机的真实画面，PNG/MP4 会以此为准。
- 摄像机视角右上有「镜头角度」面板，可用俯仰、水平、翻滚滑块匹配参考图透视。
- 地面出现倾斜时，先调「翻滚」，再点「水平归正」将翻滚归零。
- 「网格」只作水平和空间定位辅助，不会导出。

![镜头角度、水平归正和辅助网格](screenshots/monoform-camera-tools.png)

右下监看器支持「最小化」「恢复」「放大 / 恢复窗口大小」；它只是预览窗口，不会改变主摄像机参数。

![放大的摄像机监看器](screenshots/monoform-monitor-expanded.png)

## 7. 光照

点击右上「光照」打开面板。所有调整都会同步到中央视口、摄像机监看器和导出结果：

- 环境亮度：整体提亮或压暗场景。
- 主光亮度：控制主方向光强度。
- 补光亮度：减少人物或物体暗部。
- 水平方向：旋转主光来源的方位。
- 主光高度：调整主光的垂直角度。
- 画面曝光：整体曝光补偿。
- 环境色、主光色、补光色：调整三组灯光颜色。

需要回到初始效果时，点击「恢复默认光照」。

## 8. 关键帧动画

时间轴默认是**没有关键帧**的。只有点击右下的「镜头关键帧」「角色状态关键帧」或「物体关键帧」按钮后，当前帧才会写入关键帧。

### 摄像机动画

1. 把时间指针放到第 0 帧，调整摄像机位置、旋转、焦距和画面比例。
2. 点击「镜头关键帧」记录起始镜头。
3. 把时间指针移动到目标帧，再调整参数并再次点击「镜头关键帧」。
4. 播放或拖动时间轴检查运镜；关键帧之间会自动插值。

### 角色状态动画

角色关键帧会记录动作预设、动作相位、循环开关、人物位置/旋转/缩放和完整骨骼状态。因此可以制作“0–2 秒行走，2 秒摇头，3 秒自然站立”这样的状态切换。

### 编辑关键帧

点击关键帧可选中它；拖动可改时间；右侧按钮支持复制、粘贴、删除；插值菜单可选择平滑或保持。删除关键帧不会删除角色或物体本身。

![摄像机和角色关键帧](screenshots/monoform-camera-keyframes.png)

## 9. 工程保存与导出

- 「保存」：保存到当前浏览器的自动保存空间。
- 「导出工程」：下载工程 JSON，包含场景、镜头、参考图、光照和关键帧；适合备份或换电脑。
- 「打开」：导入之前导出的工程 JSON。
- 「截图 PNG」：按当前主摄像机画面导出单帧图片。
- 「导出 MP4」：按工程 FPS、镜头时长和关键帧导出视频；导出过程中不要关闭页面。

导出前检查：当前活动镜头、摄像机视角、参考图「进入导出」、时间轴起止位置、角色循环开关和光照效果。

## 10. 推荐工作流

1. 新建工程并设置工程名、FPS、镜头时长和是否循环播放。
2. 上传参考图，先调整透明度、大小和位置。
3. 添加人物和场景粗模，使用 W/E/R 完成走位、旋转和比例。
4. 调整人物动作预设，再用 Q 和骨骼滑块修正手脚、头部和重心。
5. 添加或切换摄像机，先在编辑视角布置，再进入摄像机视角确认画面。
6. 用「镜头角度」和焦距匹配参考图，必要时打开网格和水平归正。
7. 在时间轴中按“调整参数 → 点击对应关键帧按钮”的方式记录动画。
8. 调整光照，先截图 PNG 检查构图，再导出 MP4。
9. 导出工程 JSON 作为备份。

## 11. 常见问题

**参考图导出后大小不对**：确认你调整的是当前参考图，并且在摄像机视角中勾选「进入导出」；导出使用的是摄像机画面中的参考图参数。

**角色或物体被移动到另一个对象**：先在「场景层级」选择对象，再拖动；重叠区域可按住 `Alt` 点击选择底层对象。

**焦距改变看起来没效果**：焦距只改变视野范围。请确保选中摄像机，或在右下监看器中点击「选择场景中的主摄像机」，再观察摄像机视角。

**参考图挡住模型**：关闭「移动图片」编辑状态；正常状态下参考图是底层，只有编辑时才会临时显示交互边框。

**打开工程后关键帧消失**：请使用「导出工程」生成的 JSON 进行备份，不要只依赖浏览器自动保存；导入后会恢复镜头、角色状态、物体关键帧和参考图设置。

**MP4 导出很慢**：降低工程时长或 FPS，先用 PNG 检查单帧构图；导出期间保持页面打开。
